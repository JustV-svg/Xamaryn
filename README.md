# XAMARYN - GESTOR DE TAREAS

Xamaryn es un gestor de tareas sencillo, esta es la versión para telefonos de Todo-List, diviertete explorando sus funciones!!

## Edita tus tareas

Con xamaryn puedes editar las tareas creadas, asi que no te preocupes si escribes algo mal, puedes corregirlo sin problemas!!

## Persistencia de datos

Xamaryn cuenta con persistencia de datos, asi que no hay problema, cierra o apaga tu telefono las veces que quieras, tus tareas estaran seguras hasta que regreses
